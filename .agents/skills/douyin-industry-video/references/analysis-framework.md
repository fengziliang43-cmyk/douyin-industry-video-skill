# Analysis Framework

Use this reference only after subtitles or metadata are available.

## Claim Extraction

Extract:

- Main claim
- Supporting chain
- Implied assumption
- Who pays
- What would falsify it
- What the video omits

## AI Order Sponsor Chain

For AI hardware / memory / semiconductor claims, map orders as:

`hyperscaler / AI cloud capex -> GPU / ASIC -> TSMC / advanced packaging -> HBM / server DRAM / SSD -> equipment / materials / power / optical interconnect`

The question is not only "who has orders", but:

- Is the final payer a real cash-flow customer, a financed model company, a cloud commitment, or capital-market funding?
- Does the order convert to revenue, gross margin, operating cash flow, and repeat demand?
- Is the bottleneck technical, capacity, financing, power, packaging, or customer certification?
- Has the market already priced 2026-2027 profit upgrades?

## Output Shape

Keep the final answer compact:

1. Conclusion
2. What the video got right
3. What may be wrong or incomplete
4. Industry-chain map
5. Cycle-stage judgment
6. Event energy score
7. Falsification and tracking indicators
